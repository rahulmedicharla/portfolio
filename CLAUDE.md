## Overview

This is Rahul Medicharla's personal portfolio site: a single-page React app (Vite) deployed to Firebase Hosting.

## Commands

- `npm run dev` - start the Vite dev server
- `npm run build` - production build to `dist/`
- `npm run lint` - run ESLint over the project
- `npm run preview` - serve the production build locally

There is no test suite configured in this repo.

### Deployment

Deploys are automatic: pushing/merging to `main` triggers `.github/workflows/firebase-hosting-merge.yml`, which runs `npm install && npm run build` and deploys `dist/` to Firebase Hosting (project `rahul-medicharla-portfolio`, configured in `.firebaserc`/`firebase.json`). There is no preview-channel workflow for PRs. Do not deploy manually with the Firebase CLI unless asked — pushing to `main` is the deploy mechanism.

## Architecture

**Content/presentation split**: All page copy and data (name, bio, experience, projects, articles, social links) lives in a single file, `src/contents.js`, exported as one `content` object. `App.jsx` imports this and passes slices of it down as props to section components. To change any visible text, dates, links, or add/remove an experience/project/article entry, edit `src/contents.js` — do not hunt for hardcoded strings in components.

**Single-page, section-based layout**: `App.jsx` renders one long scrollable page composed of section components in order: `Header` (Spline 3D scene), `Landing`, `About`, `Experience`, `Creations`, `Explorations`, plus `Navigation`, `ScrollDown`/`ScrollUp`. Each section is its own directory under `src/components/<Name>/` with a co-located `<Name>.jsx` and `<Name>.css` (no CSS modules/styled-components — plain global-ish CSS files imported per component).

**Anchor-based navigation**: `content.anchorTags` (`["home", "about", "experience", "creations", "explorations"]`) is the single source of truth for section IDs. `App.jsx` assigns these as `id` on each section's wrapping `Row`, and `Navigation`/`Landing`/`ScrollDown`/`ScrollUp` use `react-scroll`'s `<Link to={tag} smooth>` to jump/scroll between them. When adding a new top-level section, add its tag to `anchorTags` and give the section that `id`.

**Layout system**: Uses `react-bootstrap` (`Container`/`Row`/`Col`) with responsive breakpoint props (`xs`/`sm`/`md`/`lg`/`xl`) for the entire layout grid, rather than CSS Grid/Flexbox utility classes. Follow this pattern for new sections rather than introducing a different layout system.

**Static assets**: Images used in `contents.js` (project screenshots, company logos, headshot, resume) live in `public/` and are referenced by root-relative path (e.g. `/kubefs.png`). `dist/` is a build output directory (checked into git) — never hand-edit files there; it's regenerated by `npm run build`.

**Notable dependencies**: `@splinetool/react-spline` (3D header scene), `swiper` (project carousel in `Creations`), `motion` (Framer Motion, animations), `react-scroll` (anchor navigation), `@mui/material`/`@mui/icons-material` (icons only, e.g. social links), `@codaworks/react-glow` (glow hover effects), Firebase (hosting only, no client SDK usage beyond `firebase.json` config).
